⚙️ Local Setup & Installation
1️⃣ Clone Repository
git clone https://github.com/erravikumar/Job-Portal.git
cd Job-Portal

2️⃣ Frontend Setup
cd frontend
npm install
npm start


📍 Runs at:

http://localhost:3000

3️⃣ Backend Setup
cd backend
npm install
npm start


📍 Runs at:

http://localhost:5000

🚀 Production Build
CI=false npm run build


Frontend is optimized and deployed on Vercel.
